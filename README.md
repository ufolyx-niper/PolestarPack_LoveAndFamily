# Polestar 指南 · 爱与家庭

适用于 WoW Forever，联盟和部落各职业 52 级起可接。从东瘟疫之地河畔的提里奥开始，跟随 11 个任务、17 个步骤，找回泰兰的战锤、战旗和全家福，完成壁炉谷护送并领取最终奖励。可以接到取画任务后再约斯坦索姆队伍。

## 用 WowUp 安装和更新

1. 在 WowUp 选择 **WoW Forever**，先安装依赖 [Polestar Guides](https://www.curseforge.com/wow/addons/polestar)。本包已在核心 0.4.1.1 上验证。
2. 打开 **获取插件 → 从 URL 安装**，粘贴本仓库地址 `https://github.com/ufolyx-niper/PolestarPack_LoveAndFamily`。
3. 在游戏中输入 `/polestar guides`，搜索「爱与家庭」或「弗丁」。后续正式版本可在 WowUp 的 **我的插件** 中更新，也可开启自动更新。

手动安装可从 [最新正式版](https://github.com/ufolyx-niper/PolestarPack_LoveAndFamily/releases/latest) 下载以 `-forever.zip` 结尾的附件。路线、选奖与中途接续见[玩家说明](PolestarPack_LoveAndFamily/README.md)。
