# 爱与家庭 · 提里奥的完整任务链

在 WoW Forever 的 Polestar 指南库搜索「爱与家庭」或「弗丁」。联盟和部落各职业都可以从 52 级开始，建议先留三个任务栏空位。后半段有高级精英和斯坦索姆五人副本，可以接到取画任务后再约队。

| 行程 | 任务 ID | 到站要做的事 |
| --- | --- | --- |
| 东瘟疫河边小屋 | 5542、5543、5544 | 三项一起接。在西南打幼犬、蝙蝠并拾取虫肉，再去中部和北部补齐另两种犬。三项都回小屋交付。 |
| 提里奥的往事 | 5742、5781、5845 | 坐下同他交谈。到南部墓地翻土，从伏兵首领身上取锤，先回小屋；接下一项再去北谷湖底取旗，回来交旗。 |
| 凯尔达隆与斯坦索姆 | 5846、5848 | 上岛找画家，接第二项同名任务。从斯坦索姆正门进血色区，在档案管理员房间右墙取下双月画后的肖像，回东瘟疫河畔交给提里奥。 |
| 悔恨岭与壁炉谷 | 5861、5862 | 带礼物找巫女麦兰达，接任务后再对话取得伪装，去壁炉谷城堡楼上找泰兰。组队时先让每人交礼物。 |
| 路边哨塔 | 5944 | 跟泰兰出城，护送到塔前并等剧情结束。在西瘟疫当场向出现的提里奥交任务。 |

**最终奖励五选一**。弗丁印记、精制合金胸甲、闪光白金战锤、流放者斗篷、弗丁徽记之戒。请在任务窗口比较当前角色可用的属性后再选。

**中途接续**。打开同一个指南即可按本人的任务日志继续。瘟疫犬数字以日志为准。斯坦索姆的户外箭头指向正门，进入副本后看房间和墙面说明。伪装失效去悔恨岭找麦兰达补；护送只有在日志明确失败时才需放弃重接。日志已可交而塔前无人时，保留任务并在事件终点查看下一次剧情。

**安装**。将 ZIP 中的 PolestarPack_LoveAndFamily 文件夹解压到 Forever 客户端的 Interface/AddOns，确认同名 TOC 直接位于该文件夹，启用 Polestar 0.4.1.1 或兼容版本和本包后重载。已用 0.4.1.1 核对，指引文字为简体中文，实体名称优先使用核心在客户端解析的名字。
